# CallCheck downloads

CallCheck is the Begin sales team's menu-bar app. It checks that calls from your iPhone and Wispr Flow
recording work on your Mac.

## Install (once)

1. Download **[CallCheck.dmg](https://github.com/team-begin/callcheck-releases/releases/latest/download/CallCheck.dmg)**.
2. Open it and drag **CallCheck** into **Applications**.
3. Open CallCheck from Applications. macOS will say it can't check the app. Click **Done**.
4. Open **System Settings › Privacy & Security**, scroll down and click **Open Anyway** next to CallCheck.
   Then click **Open Anyway** again and enter your Mac password.

That's the only time you do this. CallCheck updates itself after that.

This repo only holds the built app. The code is private.
